# 03 · 移动物理与碰撞

## 1. 设计目标

- 输入响应快，不使用“角色慢慢滑起来”的重惯性手感。
- 允许玩家通过短跳、长跳、二段跳和空中修正精确调整落点。
- 容忍合理的边缘操作，但不自动替玩家完成跳跃。
- 高刷新率与低刷新率设备得到一致结果。
- 移动平台、头顶边角、单向台和高速运动不产生常见穿透 Bug。

## 2. 基础尺寸与时间

| 参数 | 值 |
|---|---|
| 逻辑画面 | 1280×720 |
| 玩家碰撞体 | 30×42 |
| 固定步长 | 1/60 秒 |
| 单帧最大累计时间 | 0.05 秒 |
| 最大下落速度 | 980 px/s |

Canvas 高清比例不改变世界坐标与碰撞；1600×900 或 1920×1080 只是同一逻辑画面的更高像素密度。

## 3. 水平移动

### 标准地面

- 目标速度：330 px/s。
- 普通加速度：2850 px/s²。
- 反向急停/换向：4100 px/s²。
- 无输入地面减速：3300 px/s²。

### 空中

- 空中加速度：1820 × `airControlScale`。
- 导演“轻飘舞台”将空中修正放大到 1.22。

### 特殊表面

| 表面 | 目标速度/加速度变化 |
|---|---|
| 冰面 | 加速度 720；松键减速 135，保留明显滑行 |
| 黏性糖浆 | 目标速度 185；加速度 1200；松键减速 880 |
| 输送带 | 平台提供额外水平位移/承载运动 |

左右同时按下时使用最后一次水平方向，避免输入状态产生不可预测抖动。

## 4. 跳跃

| 规则 | 数值 |
|---|---|
| 普通起跳速度 | -640 px/s |
| 黏性台起跳 | -700 px/s，补偿黏性限制 |
| 最大跳跃次数 | 2 |
| 跳跃缓冲 | 0.12 秒 |
| 土狼时间 | 0.085 秒 |
| 松键短跳 | 当 `vy < -180` 时乘 0.52 |

### 二段跳

第一次离开地面后，玩家可在空中再触发一次完整跳跃。落到有效支撑平台后跳跃计数清零。

### 移动平台动量继承

从移动平台起跳时读取平台本帧 `deltaX/deltaY`，换算为速度后加入玩家速度，并限制在安全范围。这样玩家不会在高速平台起跳时突然失去水平动量。

## 5. 重力曲线

基础重力为 1780 px/s²。

- 接近最高点，`|vy| < 72`：重力乘 0.58，增加可控的悬停时间。
- 下落时：重力乘 1.58，让落地快速明确。
- 导演规则可乘 `gravityScale`。

这种非对称曲线使上升可读、顶点可修正、下落干脆。

## 6. 分段碰撞

高速运动如果一次把角色从 A 移到 B，可能跨过薄平台。`splitMotion(amount, maxStep=3)` 将位移拆成不超过 3 像素的小段：

```text
本帧位移 11px → 3 + 3 + 3 + 2
```

每个小段都执行碰撞查询，从而降低穿墙和穿刺概率。

### X 轴

1. 按分段移动玩家。
2. 与活动实体平台检查 AABB。
3. 碰撞时将玩家贴到平台左/右侧。
4. 水平速度清零。
5. 对假台、传送行为和特殊状态执行对应逻辑。

### Y 轴

1. 按分段移动玩家。
2. 下落时处理实体台和单向台顶部。
3. 上升时处理头顶碰撞。
4. 成功落地后：`grounded=true`、跳跃清零、记录 standing block。
5. 若平台正在移动，加入平台本帧位移。

## 7. 头顶边角修正

`findCornerCorrection()` 在头顶碰撞时尝试最多 6 像素的左右偏移：

- 如果角色只擦到平台尖角，自动横移出重叠区域并保留上升。
- 如果角色正面撞到大面积天花板，不修正，正常停止上升。

这不是自动攀爬，只是消除“明明差一点却被方形碰撞体卡死”的手感问题。

## 8. 地面探针

`findSupport(body, solids, tolerance=3)` 在角色脚下 3 像素范围寻找支撑：

- 解决浮点误差导致的落地/离地闪烁。
- 让移动平台承载更稳定。
- 只在向下运动或上一帧已落地时探测，避免上升过程被吸回平台。

## 9. 单向平台

- 只有玩家从上方向下穿过平台顶部时产生碰撞。
- 上升时可从下方穿过。
- 玩家脚底上一帧位置用于判断是否来自上方，避免侧面吸附。

## 10. 轨道、移动、相位和崩塌平台

### 移动平台

在 `baseX/baseY` 与目标之间按周期移动，保存 `lastX/lastY` 供承载与起跳动量使用。

### 轨道平台

`orbitPosition()` 使用中心、X/Y 半径、速度和相位计算椭圆轨迹。

### 相位平台

`phaseActiveAt()` 按周期切换实体/非实体。非实体时仍可显示半透明轮廓。

### 崩塌平台

状态：stable → warning → absent → restored。玩家第一次踩到后记录时间；预警结束后暂时消失，再按配置恢复。

## 11. 摄影机与操作舒适度

- 横向死区：屏幕 40%–56%。玩家在死区内移动，镜头完全不动。
- 超出死区后，目标只移动到对应边界，不把角色强行居中。
- 平滑率默认 4.8。
- 远景偏移固定为 0，背景不产生视差晃动。
- 震动使用低振幅正弦组合；减少动态模式时完全关闭。

## 12. 常见 Bug 与防线

| Bug | 防线 |
|---|---|
| 高速穿墙 | 3 像素分段运动 |
| 天花板尖角卡死 | 6 像素角落修正 |
| 移动平台脚下闪烁 | 3 像素支撑探针 |
| 起跳失去平台速度 | 平台动量继承 |
| 低帧跳跃变矮 | 固定 1/60 步长 |
| 松键无短跳 | 上升速度乘 0.52 |
| 重生立即死亡 | 检查点数据测试与机关重置 |
| 摄影机换向甩动 | 无方向前视 + 宽死区 |

## 13. 手感验收

- 连续 100 次普通跳跃，最高点误差不应随显示刷新率变化。
- 边缘离台后 0.085 秒内按跳仍成功。
- 落地前 0.12 秒按跳，落地首个更新步立即起跳。
- 正面撞顶停止；轻擦尖角可修正。
- 在移动平台上静止时相对位置稳定。
- R 重开不会保留上一尝试的速度。
