# 05 · 叙事、美术与音频

## 1. 叙事前提

主角是失去颜色和记忆的白色纸偶/黏土人。他在梦境游乐园醒来，被告知自己只是演员。笑脸园长把主角的记忆加工成糖果、马戏、镜子和城堡机关，要求主角持续表演。

随着 12 段核心记忆恢复，玩家发现：

- 乐园并非单纯外部监狱，而是记忆实验系统；
- 园长是主角为继续实验而留下的执行人格；
- 主角曾主动进入机器以逃避责任；
- 真正的选择不是“忘掉痛苦”，而是如何带着记忆生活。

## 2. 叙事原则

1. **短文本，不打断动作。** 房间卡、Toast 和收集物承担大部分叙事。
2. **环境先于解释。** 招牌、地标、错误广播和舞台机器暗示世界真相。
3. **死亡属于世界观。** 系统把失败当作演出数据，而非传统英雄死亡。
4. **结局由收集行为决定。** 玩家是否主动寻找记忆体现角色面对过去的程度。
5. **黑色幽默不写实血腥。** 暴力表现保持纸偶、玩具和舞台道具语境。

## 3. 核心记忆叙事顺序

12 段核心记忆从“第一次开园”逐步揭示服从协议、失败记录、演员来源、虚假观众、关闭失败、镜中人格、现实来信、焚化许可和主动入机，最后指出真正出口。

文本功能：

- 1–3：建立实验不道德。
- 4–6：揭示角色与系统关系。
- 7–9：揭示园长与现实牵挂。
- 10–12：揭示主角责任与最终选择。

## 4. 四个结局

### 逃离

收集不足。主角离开当前舞台，但没有理解循环，因此园长仍可继续。

### 接管

理解部分真相，却选择成为新的管理者，以控制代替面对。

### 摧毁

集齐 12 段核心记忆，关闭乐园，承认真相。

### 带着记忆生活

集齐核心记忆和全部员工档案，并在终章走向隐藏方向。主角不删除痛苦，也不继续扮演园长，而是带着完整记录回到现实。

## 5. 美术方向

### 5.1 风格关键词

- 纸雕剧场；
- 黏土玩具；
- 手工道具；
- 哑光材质；
- 深色墨线；
- 不完美裁切；
- 暖色灯光下的不安感。

### 5.2 为什么不用像素风

项目需要与常见高难平台原型区分，并让陷阱拥有“舞台道具突然活过来”的表现。Canvas 矢量路径可在 1600×900–1920×1080 保持清晰，也方便程序化生成圆角、纸纹、灯光和变形。

## 6. 章节视觉语言

### 糖果迎宾区

- 暖粉、奶油黄、糖纸红、薄荷绿。
- 形状圆润，但危险尖刺使用高饱和红色与深墨线。
- 礼盒、棒糖、糖浆与压榨机形成“可爱工业线”。

### 失控马戏团

- 红幕、金色灯泡、旧纸票、深紫阴影。
- 三角旗、弹床、大炮、聚光灯和观众席。
- 场景更强调舞台中央与表演节奏。

### 镜像鬼屋

- 冷绿、灰紫、半透明镜面、高亮裂纹。
- 重复椭圆、双影和对称结构。
- 危险轮廓保持暖红，以免与背景混淆。

### 梦境城堡

- 深紫、铜金、熔炉红、机械青绿。
- 齿轮、钟表、城墙和控制机器。
- 前三章色彩作为“被机器回收的记忆”局部出现。

## 7. Canvas 绘制方法

### 7.1 形状语言

- `roundRect` 统一纸板圆角。
- 粗深色描边形成剪纸边缘。
- 线性渐变制造纸张折面和黏土体积。
- 径向渐变用于灯光、角色头部和舞台暗角。
- 稳定伪随机 `visualSeed()` 生成纸纹，确保同一房间每次一致。

### 7.2 层级

1. 纸张天空和远景。
2. 世界招牌与大型地标。
3. 平台和机关。
4. 危险与攻击线。
5. 收集物、出口、玩家。
6. 粒子与导演覆盖。
7. 前景帷幕。
8. DOM HUD。

### 7.3 可读性

- 危险使用统一高饱和色与粗轮廓。
- 预警用虚线、脉冲和音效，实体攻击用实心形状。
- 平台顶部有高亮边，底部有暗面。
- 动作锁文字同时提供中文状态与图形/英文短码。
- 颜色友好模式为危险增加不同形状/高亮，而不只换色。

## 8. 高清渲染

- 逻辑画面保持 1280×720，设计坐标不随设备变化。
- backing canvas 至少 1600×900，最大 1920×1080。
- 所有静态缓存同样按高清比例重建，避免低清背景被放大。
- 大屏时由浏览器将高清画布映射到 CSS 尺寸，边缘更锐利。
- 不使用 `image-rendering: pixelated`，保持矢量边缘平滑。

## 9. 角色表现

主角由 Canvas 基础形状组成：

- 椭圆头部、圆角矩形身体、线条四肢；
- 跑步时四肢按速度摆动；
- 空中上升和下落使用不同腿部姿态；
- 起跳产生挤压拉伸；
- 围巾颜色随章节改变；
- 眼睛眨动与朝向跟随面对方向；
- 下落时表情变为惊讶。

死亡不绘制血液，而是生成纸片粒子和压扁残影。

## 10. 大型地标

12 个章节地标承担三项功能：

1. 让 3440 像素宽房间有明确视觉记忆点；
2. 预告本关主要机关；
3. 在剧情上表现记忆被机器加工。

例如糖果压榨机暗示压榨机关，掌声之眼暗示观众监控，记忆焚化炉暗示销毁许可。

## 11. 音频架构

`AudioSystem` 使用 WebAudio 动态创建：

- `master` 总线；
- `musicGain` 音乐；
- `sfxGain` 音效；
- `ambientGain` 环境。

所有声音由 oscillator + gain 包络生成，无外部音频文件。

## 12. 音乐设计

- 每章使用一组不同音高序列。
- 前两章偏 triangle/square 玩具音色。
- 后两章增加 sine、sawtooth、失谐和低频环境音。
- Boss 按节拍加入低频打击和半音偏移。
- 进入更后面的关卡段落时增加高频节奏层。
- 章节越后，节拍略变慢或更机械，表现乐园失控。

## 13. 音效映射

| 事件 | 音色目的 |
|---|---|
| 跳跃 | 两段上扬短音，确认输入 |
| 落地 | 低频短音，确认接地 |
| 死亡 | 由高到低的锯齿音阶 |
| 检查点 | 三音上行，表示安全记录 |
| 按钮 | 机械双击 |
| 动作锁成功 | 四音快速上行 |
| 动作锁失败 | 低沉失谐双音 |
| 预警 | 高频短促提示 |
| 大炮 | 低频爆发 + 上行尾音 |
| 压榨机 | 低频冲击 |
| 擦弹 | 清脆高频奖励 |
| 合同完成 | 完整和弦式上行 |

## 14. 浏览器音频规则

- 首次点击进入游戏时调用 `audio.unlock()`，遵守浏览器自动播放限制。
- 暂停、失焦和隐藏页面时音乐/环境总线平滑降为 0。
- 音效开关与音乐开关独立。
- 主音量和分总线音量保存到当前槽位设置。
- 不在标题页自动创建持续音频，避免用户不知道哪个页面发声。

## 15. 美术与音频验收

- 1920×1080 截图边缘无明显锯齿或低清放大。
- 危险在四章背景中均可快速识别。
- 预警与实体攻击的颜色/线型不同。
- 关闭主音量后所有总线静音。
- 页面失焦后无持续声音。
- 死亡表现无写实血腥。
- 不加载任何第三方图片、字体、音乐或音效 URL。
